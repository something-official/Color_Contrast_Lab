# Color Contrast Lab

Color Contrast Lab turns an accessibility concept into a small, inspectable project. Change the two color inputs, read the calculated ratio, and compare normal and large text guidance. The source is intentionally compact so you can connect the formula, DOM events, and a useful UI state without a framework.

## What this demonstrates

- Relative luminance and contrast-ratio calculations
- Accessible form labels and live status messaging
- DOM events and derived UI state
- Designing clear pass, review, and error states
- Translating a standard into a practical tool

## Run it

Open index.html in a modern browser, or serve this folder with any static file server. The project has no build step or external dependency.
